# CropDiary AI — Known Limitations & Service Boundaries
*Transparent Inventory of Dependencies, Fallbacks, and Operational Assumptions*

---

## 1. External Service Dependencies & Graceful Fallbacks

CropDiary AI is built defensively to ensure zero crashes when external infrastructure is absent or rate-limited:

| External Service | Role in Platform | Production Requirement | Graceful Fallback When Offline or Missing |
|---|---|---|---|
| **Supabase Cloud PostgreSQL** | Cloud persistence, GoTrue Auth, and Storage buckets | `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` | Automatically shifts to **Local Development Mode** with isolated browser storage and native IndexedDB offline queuing. |
| **Google Gemini API** | Multi-modal visual plant pathology and bilingual speech/text reasoning | `VITE_GEMINI_API_KEY` | Uses embedded **ICAR / TNAU Ground-Truth Rulebase** for disease diagnosis and deterministic intent matching. |
| **Open Data Government (Agmarknet)** | Intraday APMC mandi wholesale commodity prices | `VITE_DATAGOV_API_KEY` | Displays **Directorate of Marketing & Inspection (DMI) verified benchmark price ranges** for key crops. |
| **Open-Meteo API** | Meteorological forecasting and agro-spray windows | Free Tier (No API key required) | Uses cached forecasts from IndexedDB or regional agro-climatic averages if device has zero network. |

## 2. Browser & Platform Boundaries

1. **IndexedDB Storage Quotas & Private Browsing**:
   - The offline sync engine requires browser IndexedDB support (standard across modern Chrome, Edge, Safari, Firefox, and Android WebView).
   - In Incognito / Private Browsing mode, some browsers severely restrict IndexedDB storage limits or wipe storage upon tab closure. For persistent offline operation in the field, standard browser profiles or installed PWA mode is recommended.
2. **Web Speech API Regional Recognition**:
   - The Tamil voice input feature relies on browser-native SpeechRecognition (`webkitSpeechRecognition`).
   - Chrome on Android and desktop provides native `ta-IN` speech-to-text models; however, Firefox desktop has limited Web Speech API support by default. The platform provides a standard text input fallback in all browsers.
3. **Camera & Photo Capture in Mobile Browsers**:
   - Mobile web file inputs trigger the native camera via `capture="environment"`. On desktop laptops without webcams, the interface accepts standard file picker uploads.

## 3. Agricultural & Agronomic Scope

1. **Crop Template Catalog**:
   - The Smart Crop Planner contains comprehensive agronomic data for 10 primary Indian crops (Paddy, Cotton, Maize, Blackgram, Groundnut, Tomato, Sugarcane, Banana, Chilli, Turmeric). Crops outside this catalog can be tracked in the Farm Diary but do not have automated scoring algorithms.
2. **Provisional Nature of AI Plant Pathology**:
   - Visual plant assessments generated by the AI Crop Doctor represent provisional diagnostic hypotheses (`diagnosis_status: preliminary_possible`), not clinical or laboratory certification. For rapidly spreading symptoms or severe canopy dieback, farmers are directed to physical Krishi Vigyan Kendra (KVK) facilities or the national Kisan Call Centre (1800-180-1551).
3. **Yield Projection & Non-Guarantee Boundary**:
   - Crop Planner economic returns and yield projections represent estimated potential ranges under standard agronomic management. CropDiary AI explicitly displays non-guarantee yield disclaimers; actual outcomes remain subject to unpreventable weather extremes, local soil variations, and water availability.
4. **Financial Realization Lifecycle & In-Progress Tracking**:
   - Historical seasonal comparisons explicitly track data completeness. Active seasons without harvest sales or with stored inventory are designated as `In Progress / Harvest Stored (Unsold)` to prevent premature comparison against fully liquidated historical seasons.
5. **Pesticide Safety Boundary**:
   - CropDoctor strictly blocks WHO Class Ia and Class Ib acutely hazardous pesticides and prioritizes non-chemical IPM. It does not provide off-label chemical recommendations for experimental agrochemicals.
6. **Currency Precision**:
   - Financial bookkeeping operates strictly in Indian Rupees (INR) using 2-decimal minor units ($1.00\text{ INR} = 100\text{ paise}$). Multi-currency conversions (USD, EUR) are not currently required for domestic Indian farming operations.
